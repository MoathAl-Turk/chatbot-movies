# hussBot: Movie Recommendation Chatbot 🎬

**[Try it live here!](https://moathal-turk.github.io/chatbot-movies/)**

## Overview
hussBot is a web-based movie recommendation chatbot designed to help users discover films. It integrates the OpenRouter API with a custom Kaggle movie dataset to process user prompts and deliver accurate, tailored movie suggestions. 

*Note: For security reasons, the API key is not hardcoded. You will need to provide your own OpenRouter API key when prompted on the site to use the chatbot.*

## Tech Stack
* **Frontend:** HTML, CSS, JavaScript
* **Backend/API:** OpenRouter API
* **Data:** Kaggle Movie Dataset

## How to Use the Live Demo
1. Visit the [live site](https://moathal-turk.github.io/chatbot-movies/).
2. If you don't have one, generate an API key from [OpenRouter](https://openrouter.ai/).
3. Enter your API key into the prompt on the website.
4. Start asking for movie recommendations!

## Local Setup (For Developers)
If you want to view or modify the code locally:
1. Clone the repository: `git clone https://github.com/MoathAl-Turk/chatbot-movies.git`
2. Open `index.html` in your web browser.
3. Just like the live site, it will prompt you to enter your OpenRouter API key to function.
